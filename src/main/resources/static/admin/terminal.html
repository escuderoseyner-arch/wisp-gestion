Terminal remota

El MikroTik ejecuta el comando en su próxima consulta y devuelve la salida.

Atención: el comando se ejecuta en el router REAL, con todos los permisos del script. Un comando equivocado puede dejar sin internet a los clientes o cortar el acceso remoto al MikroTik (por ejemplo, tocar el firewall, las rutas, el script "puente" o sus tareas programadas). Revisa bien antes de enviar. No se aceptan comandos que mencionen fasttrack.
