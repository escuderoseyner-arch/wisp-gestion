La cola del MikroTik que agrupa a los clientes. El sistema nunca la modifica.

Otras colas del router que el sistema nunca debe tocar, separadas por coma.

Solo lectura: el MikroTik solo informa, la web no le envía cambios. Control: la web también le envía los cambios de las colas de los clientes.

Token del MikroTik

20 a 128 caracteres: letras, números y . _ ~ + / = - Es la misma clave que usa el script "puente" del router. Solo se guarda su hash.

Cambiar token

El token actual deja de funcionar al instante, también para el script "puente" del MikroTik. Si solo entras al router por el puente, perderás el acceso remoto hasta poner la nueva clave en el router.

Script para el MikroTik

Crea (o reemplaza) solo el script y la tarea programada wisp-sync. No toca el script puente, el firewall ni otras colas. Antes, instala los certificados raíz (ver MIKROTIK.md).

La web solo guarda su hash: escríbelo para incluirlo en el script.

La URL no es HTTPS: el router no podrá verificar el certificado. Solo sirve para pruebas locales. Configura APP_URL_PUBLICA en Render.

Pégalo completo en la terminal del MikroTik (New Terminal en Winbox). Contiene el token: no lo compartas.
